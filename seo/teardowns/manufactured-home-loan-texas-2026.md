## KEY DATA POINTS
- Chattel: 5-10% down, 7.5-12% rate, 10-20 yr terms, no real property requirement
- FHA Title II: 580+ FICO, 3.5% down, permanent foundation + own land (or buy together)
- VA: 620+ FICO, 0% down, permanent foundation required
- USDA: 640+ FICO, 0% down, USDA-eligible area
- Conventional: 680+ FICO, 5-20% down
- MH Advantage: 3% down, site-built rates, requires MH Advantage sticker (factory-built to HUD code with site-built features)
- Real property conversion: file TDHCA Statement of Ownership and Location, attach to land, eliminate vehicle title
- ROAD to Housing Act: signed July 11, 2026 — allows chassis-optional manufactured homes; HUD must publish updated standards before manufacturing begins
